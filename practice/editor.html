작업하던 내용이 있어요

① 새 문항 추가

문항을 캡처해서 여기에 붙여넣기(Ctrl+V)
또는 이미지 파일을 끌어다 놓기 · 클릭해서 선택
캡처: 윈도우 Win+Shift+S / 맥 Cmd+Shift+4
발문부터 ⑤번 선지까지 한 문항 전체를 담아 주세요.

시험 코드: - (그림 파일 이름에 쓰여요)

② 문항 목록 · 단원 바꾸기

단원·정답을 고르거나 해설을 고치면 노란색으로 표시됩니다. 초록색은 새로 추가한 문항입니다. 「숨김」을 켜면 학생 화면에서 빠집니다.

그림번호단원정답해설숨김

③ GitHub에 올리기

  1. 받은 zip 파일의 압축을 풉니다.
  2. GitHub 저장소에서 practice 폴더를 눌러 안으로 들어갑니다.
  3. Add file → Upload files 를 누르고, 압축을 푼 파일들을 전부 선택해서 끌어다 놓습니다.
  4. 맨 아래 Commit changes 를 누릅니다. 1~2분 뒤 사이트에 반영됩니다.
